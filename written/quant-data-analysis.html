一、考情分析与备考策略

模块 题量 难度 性价比
数量关系 5-10题 ⭐⭐⭐⭐⭐ 低（耗时长，建议放最后）
资料分析 10-15题（2-3篇材料） ⭐⭐⭐ 极高（公式固定，必须拿分）
💡 备考策略：
  • 资料分析是重中之重：公式就那几个，练熟了正确率能到90%，是职测得分基本盘
  • 数量关系学会取舍：只做简单题（工程、利润、容斥），难题直接蒙，不要死磕
  • 答题顺序：资料分析放前面做（头脑清醒），数量关系放最后做（有时间就做，没时间就蒙）

二、数量关系高频题型

考点1：工程问题（必考，最简单）

📐 核心公式：工作总量 = 工作效率 × 工作时间
解题方法：赋值法——给工作总量赋值为时间的最小公倍数，算出效率，再求解

【典型例题】一项工程，甲单独做需要10天完成，乙单独做需要15天完成。两人合作需要几天完成？

A. 5天   B. 6天   C. 7天   D. 8天

【答案】B

【解析】赋值工作总量为10和15的最小公倍数30。
甲的效率 = 30÷10 = 3
乙的效率 = 30÷15 = 2
合作效率 = 3+2 = 5
合作时间 = 30÷5 = 6天

【速记】工程问题先赋值，总量取最小公倍数，效率一算答案出。

考点2：行程问题

📐 核心公式：路程 = 速度 × 时间
相遇问题：路程和 = 速度和 × 相遇时间
追及问题：路程差 = 速度差 × 追及时间
流水行船：顺水速度 = 船速+水速；逆水速度 = 船速-水速

【典型例题】甲乙两人从A、B两地同时出发相向而行，甲的速度是60km/h，乙的速度是40km/h，3小时后两人相遇。A、B两地相距多少公里？

A. 200km   B. 250km   C. 300km   D. 350km

【答案】C

【解析】相遇问题，路程和 = 速度和 × 时间 = (60+40)×3 = 300km。

考点3：利润问题

📐 核心公式：
利润 = 售价 - 成本
利润率 = 利润÷成本 × 100%
售价 = 成本 × (1+利润率)
打折：售价 = 定价 × 折扣

【典型例题】某商品按定价的8折出售，仍能获得20%的利润。问定价时期望的利润率是多少？

A. 40%   B. 50%   C. 60%   D. 70%

【答案】B

【解析】赋值成本为100元。
8折出售仍获利20%，则售价 = 100×(1+20%) = 120元
这是定价的8折，所以定价 = 120÷0.8 = 150元
期望利润率 = (150-100)÷100 = 50%

【速记】利润问题赋值成本为100，所有价格都好算。

考点4：容斥问题

📐 两集合公式：A∪B = A + B - A∩B
三集合公式：A∪B∪C = A+B+C - A∩B - B∩C - A∩C + A∩B∩C

考点5：排列组合与概率

这是数量关系中最难的题型，建议基础薄弱的考生直接放弃，把时间留给资料分析。如果要做，记住：

  • 分类用加法（要么…要么…）
  • 分步用乘法（先…再…）
  • 排列A：有顺序（排队、安排座位）
  • 组合C：无顺序（选几个人、分组）

三、资料分析核心公式

资料分析是必须拿分的模块，公式全部背下来，配合速算技巧，正确率可以稳定在85%以上。

考点1：增长率（必考）

概念 公式 说明
增长率 (现期-基期)÷基期 = 增长量÷基期 又叫增速、增幅
基期量 现期÷(1+增长率) 已知现期和增速求基期
现期量 基期×(1+增长率) 已知基期和增速求现期
增长量 现期-基期 = 基期×增长率 = 现期÷(1+增长率)×增长率 三个公式灵活选用
年均增长率 现期 = 基期×(1+r)^n（n为年份差） r为年均增长率

【典型例题】2025年某省GDP为5万亿元，比上年增长8%。问2024年该省GDP约为多少万亿元？

A. 4.43   B. 4.63   C. 4.83   D. 5.03

【答案】B

【解析】已知现期和增长率求基期：基期 = 现期÷(1+增长率) = 5÷1.08 ≈ 4.63万亿元。

【速算】5÷1.08，1.08×4.6=4.968，接近5，所以答案约4.63，选B。

考点2：比重（高频）

📐 核心公式：
比重 = 部分÷整体 × 100%
两期比重差：现期比重 - 基期比重 = (A/B) × [(a-b)/(1+a)]
（A是部分现期，a是部分增速；B是整体现期，b是整体增速）
判断升降：a > b，比重上升；a < b，比重下降

【典型例题】2025年某省粮食总产量1000万吨，同比增长5%。其中玉米产量400万吨，同比增长8%。问2025年玉米产量占粮食总产量的比重比上年（ ）

A. 上升了   B. 下降了   C. 不变   D. 无法判断

【答案】A

【解析】两期比重比较，只需要看部分增速和整体增速。玉米增速a=8%，粮食整体增速b=5%，a > b，所以比重上升。直接选A，不需要计算具体数值！

【速记】两期比重比较题，先看增速大小，大部分题直接出答案，不需要算。

考点3：平均数与倍数

概念 公式
平均数 总量÷份数
平均数增长率 (a-b)÷(1+b)，a是总量增速，b是份数增速
倍数 A是B的几倍 = A÷B；A比B多几倍 = A÷B - 1
翻番 翻n番 = 原来×2^n

四、速算技巧大全

资料分析80%的时间花在计算上，掌握速算技巧能节省一半时间。

技巧1：截位直除法（最常用）

当选项差距大时，分子分母同时截取前2-3位进行计算，忽略后面的位数。

例：34567÷12345，截取前三位 → 346÷123 ≈ 2.81，实际值约2.80，误差极小。

原则：选项首位不同，截2位；选项首位相同第二位不同，截3位。

技巧2：特殊分数法

把百分数转化为分数，简化计算。必须记住的特殊分数：

分数 1/2 1/3 1/4 1/5 1/6 1/7 1/8 1/9
百分数 50% 33.3% 25% 20% 16.7% 14.3% 12.5% 11.1%

【应用】求增长量：现期12000，增长率25%，求增长量。

常规算法：12000÷(1+25%)×25% = 12000÷1.25×0.25 = 2400

特殊分数法：25% = 1/4，增长量 = 现期÷(n+1) = 12000÷(4+1) = 2400。一步出答案！

【公式】增长率 = 1/n 时，增长量 = 现期÷(n+1)，减少量 = 现期÷(n-1)。

技巧3：分数比较法

比较两个分数大小：

  • 分子大分母小 → 分数大（直接判断）
  • 分子分母都大 → 看增速，分子增速快则分数大
  • 直除看首位 → 一个商3开头，一个商2开头，直接比

技巧4：同位比较法

比较A×B和C×D的大小，比较A/C和D/B的大小即可。

五、考场实战技巧

📊 数量+资料答题时间分配建议
资料分析
20-25分钟
10-15题
数量关系
5-10分钟
挑简单题做

资料分析是得分重点，数量关系学会放弃。

资料分析做题步骤

  1. 先看问题：圈出时间、主体、考点（求什么）
  2. 再找数据：带着问题回材料找对应数据，不要通读材料
  3. 列式计算：套用公式，用速算技巧
  4. 看选项：选项差距大就大胆估算，差距小就精算

数量关系做题策略

  1. 快速扫题：10道题用1分钟扫一遍，标记出简单题
  2. 先做简单题：工程、利润、容斥、年龄问题，这些是送分题
  3. 难题直接蒙：排列组合、复杂行程、几何难题，不要浪费时间
  4. 蒙题技巧：选项有升降变化的，答案在中间值；极值问题问最大选次大，问最小选次小
📌 最后提醒：职测考的不是"会不会"，而是"快不快"。资料分析公式必须背到滚瓜烂熟，速算技巧必须练成本能。数量关系不要强求全对，能做对5-6道简单题，剩下的蒙，就已经超过大部分人了。
